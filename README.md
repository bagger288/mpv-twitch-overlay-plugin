# Twitch mpv Overlay & Desktop Launcher

Нативный высокопроизводительный плагин оверлея чата для видеоплеера **mpv** (`twitch_chat.dll`) и десктопный менеджер-лаунчер (`twitch_launcher.exe`), полностью написанные на **Rust**.

---

## 🚀 Основные компоненты

### 1. Плагин оверлея для mpv (`twitch_chat.dll`)
Нативный C-плагин для плеера mpv с прямым рендерингом на GPU/CPU через `tiny-skia` и `fontdue`:
- **Синхронизированный чат:** посимвольное и пословное отображение чата Twitch поверх видео в реальном времени.
- **Поддержка эмоутов и бейджей:** 7TV, BetterTTV, FrankerFaceZ и нативные смайлы Twitch (включая анимированные GIF/WebP).
- **Интерактивное управление мышью:** перемещение окна чата по экрану drag-and-drop, масштабирование шрифта, изменение прозрачности и сворачивание в компактную иконку.
- **Поиск по чату:** мгновенный поиск по ключевым словам и таймкодам с поддержкой русской и латинской раскладок (`twitch_chat_input.lua`).

### 2. Десктопный лаунчер (`twitch_launcher.exe`)
Современный интерфейс на фреймворке **Slint**:
- **Каталог записей:** список локальных сессий с датами, длительностью, автоопределением стримера и метаданными. Запуск воспроизведения в mpv в один клик.
- **Прямая запись стримов:** интеграция со Streamlink для фонового скачивания трансляций и одновременного логирования IRC-чата в JSONL.
- **PC Agent:** автономный фоновый агент мониторинга онлайна избранных стримеров с автоматическим стартом и завершением записи.
- **Импорт сторонних VOD:** импорт готовых видео (`.mp4`, `.ts`, `.mkv`) с загрузкой чата Twitch VOD по API и синхронизацией таймкодов.
- **Системный трей:** сворачивание в область уведомлений при закрытии, контекстное меню, динамический тултип и статус.
- **Живая статистика:** таймер длительности, реальный размер файла на диске и счётчик сообщений в реальном времени.
- **Проверка зависимостей:** автоматическая валидация путей mpv, Streamlink и FFmpeg (с проверкой аппаратного NVENC).

---

## 🛠 Требования

- **ОС:** Windows 10 / 11 (x64)
- **mpv:** плеер mpv (с поддержкой загрузки C-плагинов)
- **Streamlink:** для записи живых трансляций Twitch
- **FFmpeg:** для импорта, нарезки и экспорта видео
- **Rust Toolchain:** `stable-x86_64-pc-windows-msvc` (для самостоятельной сборки)

## 📦 Сборка проекта

Проект организован как Cargo Workspace. Сборка всех компонентов (лаунчера и dll-плагина) выполняется одной командой:

```bash
# Сборка всех компонентов в режиме release
cargo build --release
```

После завершения сборки исполняемые файлы будут доступны в:
- `target/release/twitch_launcher.exe` — десктопный лаунчер
- `target/release/twitch_chat.dll` — нативный плагин оверлея для mpv

---

## ▶️ Запуск

1. Запустите `target/release/twitch_launcher.exe`.
2. На вкладке **«Настройки»** укажите пути к `mpv.exe`, `streamlink.exe` и `ffmpeg.exe` (или нажмите *«🔍 Проверить утилиты»* для автопоиска в PATH).
3. При необходимости укажите Twitch Client ID и App Access Token для загрузки эмоутов каналов.
4. Выберите нужную сессию на вкладке **«Записи»** и нажмите **«▶ Воспроизвести»**!
