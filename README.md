# Twitch Chat mpv Plugin (Rust Native C-Plugin)

Высокопроизводительный нативный плагин для плеера **mpv** на языке **Rust**, компилируемый в динамическую библиотеку (`twitch_chat.dll` для Windows).

Полная замена связки **Lua + IPC-сокет + Python-скрипт**. Обеспечивает мгновенный отклик мыши (< 1 мс), отрисовку 60 кадров/сек без просадок FPS видео, поддержку эмоутов (Twitch, 7TV, BTTV, FFZ) и значков, автоперенос строк (Word-wrap) и навигацию по чату (Click-to-Seek).

---

## ⚡ Преимущества нативного Rust перед Python/Lua

| Параметр | Старая связка (Lua + Python) | Нативный Rust (`twitch_chat.dll`) |
|---|---|---|
| **Архитектура** | 2 процесса, IPC сокет / пайп, буферизация | Внутри процесса mpv (0 IPC, прямой C API) |
| **Отклик мыши** | 50–200 мс (заметный input lag при скролле) | **< 1 мс** (мгновенная реакция) |
| **FPS оверлея** | 10–20 FPS (нагрузка на CPU Pillow) | **Плавные 60 FPS** (минимальная нагрузка) |
| **Установка** | Требуются Python 3.10+, pip, Pillow, aiohttp | **0 зависимостей**: просто скопировать `.dll` |
| **Парсинг JSONL** | ~1-3 секунды на больших логах | **< 50 мс** на многочасовой лог |

## 🚀 Сборка через GitHub Actions (с кэшированием)

В репозитории настроен автоматический CI/CD workflow: [`.github/workflows/build-rust-plugin.yml`](../../.github/workflows/build-rust-plugin.yml).

### Как получить готовую `.dll`:
1. Запушьте изменения в репозиторий GitHub.
2. Перейдите во вкладку **Actions** -> **Build Twitch Chat mpv Rust Plugin (Windows x64)**.
3. Можно также запустить сборку вручную через кнопку **Run workflow** (выбрав профиль `release` или `debug`).
4. Благодаря кэшу `Swatinem/rust-cache@v2` повторная пересборка занимает **меньше минуты**.
5. Скачайте готовый артефакт **`twitch_chat-windows-x64`** с файлом `twitch_chat.dll`.

## 💻 Установка и использование в mpv

1. Положите файл `twitch_chat.dll` в папку скриптов mpv:
   * **Обычная установка mpv**: `C:\Users\<Имя>\AppData\Roaming\mpv\scripts\`
   * **Портативный mpv**: папка `mpv/scripts/` или `mpv/portable_config/scripts/`
   
2. Либо укажите при запуске видео через консоль:
   ```cmd
   mpv --script="C:\path\to\twitch_chat.dll" "records/channel_date/part.ts"
   ```

3. Плагин автоматически:
   - Обнаружит находящиеся рядом файлы `.session.json`, `.chat.jsonl` и `.emotes.json`.
   - Подгрузит эмоуты из папки `emote_cache/`.
   - Начнет отображать синхронный оверлей поверх видео.

## 🎮 Возможности оверлея

- **Плавный скролл истории**: крутите колесико мыши вверх — чат приостанавливается с плашкой `[Чат приостановлен | Клик: Вниз к live]`.
- **Click-to-Seek**: кликните по любому сообщению левой кнопкой мыши — видео мгновенно перемотается на момент отправки этого сообщения.
- **Поддержка эмоутов и бейджей**: кэшированные PNG/WebP смайлики рисуются прямо в строке текста.
- **Автоперенос строк (Word-wrap)**: длинные фразы не вылезают за границы панели.
- **Настройка прозрачности и масштабирования**: пропорциональный размер эмоутов под размер шрифта.

## 🛠 Локальная сборка (для разработчиков на Windows)

Если у вас установлен Rust (`rustup`):
```powershell
cd twitch_records/rust_plugin
cargo build --release
```
Файл библиотеки будет сгенерирован по пути:
`target/release/twitch_chat.dll`.
